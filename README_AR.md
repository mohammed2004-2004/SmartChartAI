# Smart Chart AI — مشروع أندرويد أولي

هذا مشروع بداية لتطبيق عائم على Android 14. النسخة الحالية تعرض لوحة عائمة تجريبية فوق التطبيقات، بعد منح إذن "الظهور فوق التطبيقات الأخرى".

## مهم جداً
- هذا **ليس APK جاهزاً للتثبيت**؛ إنه مصدر مشروع Android.
- هذه النسخة لا تقرأ الشموع أو الأسعار من MT5 بعد، ولا تحسب RSI أو الدايفرجنس فعلياً.
- قراءة الشاشة تحتاج موافقة المستخدم عبر Android MediaProjection، ثم يلزم تطوير معالجة صورة/بيانات أسعار واختبارها.
- خطوط الرسم في هذه النسخة تجريبية فقط، وليست تحليلاً للسوق.
- لا تضع بيانات دخول Weltrade داخل التطبيق.

## الملفات
- `app/src/main/AndroidManifest.xml`: تعريف التطبيق والصلاحيات.
- `MainActivity.kt`: واجهة بدء بسيطة.
- `OverlayService.kt`: لوحة عائمة وخطوط توضيحية فوق التطبيقات.

## البناء
يحتاج المشروع إلى Android Studio أو بيئة بناء Android مع Android SDK وGradle. افتح مجلد المشروع في Android Studio، ثم ابنِ APK تجريبياً. لم يُنتج APK في هذه البيئة لأن Android SDK/Gradle غير متاحين هنا.

## المرحلة التالية
1. إضافة موافقة التقاط الشاشة باستخدام MediaProjection.
2. التقاط صورة لشارت MT5 فقط بعد موافقة المستخدم.
3. تحديد منطقة الرسم ومقياس السعر والشموع.
4. إضافة دعم/مقاومة وترند وRSI من بيانات موثوقة، مع توضيح أن نتائج الصورة قد تخطئ.
